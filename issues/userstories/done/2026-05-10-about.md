# Enrich About Screen with App Info, Attribution, and GitHub Link

Let's improve "About" screen. I want it to have:

- The title: **Competition Manager Mobile**
- Short description (1-2 sentences)
- Version
- Written by Andrey Lebedev
- Link to github project (for bugsm support, soruce code) https://github.com/kedder/compman-mobile
- Data is provided by:
   - Competition data: [Soaringspot](https://www.soaringspot.com/)
   - XCSoar tasks: [Soarscore](https://soarscore.com/)

## Product Owner Notes

### What the user wants

The current About screen (`/about` route, `AboutScreen` in `lib/app.dart`) is minimal: it
shows only the app name "Compman Mobile", the runtime version from `package_info_plus`, and
a single line "Data provided by SoaringSpot". The user wants a complete, informative About
screen that serves two purposes:

1. **Identity and authorship** — app title, a brief description, version, and the author's name.
2. **Transparency and support** — link to the GitHub project (source code, issue tracker, bug
   reports) and clear attribution for each external data source the app depends on.

### Screens affected

Only the existing `/about` route is touched. The screen is a static informational page with
no async complexity beyond the already-loaded version string.

### Proposed UI layout

The screen uses a single-column scrollable `ListView` (or `Column` inside a `SingleChildScrollView`)
with the following sections, top to bottom:

1. **App identity block** — centered column containing, in order:
   - **App icon** — `Image.asset('assets/icon/app_icon.png')` rendered at **96 × 96 dp**.
     This display size is chosen to be legible without dominating the screen; the source image
     is 1024×1024 px (RGBA PNG) so Flutter's box-fit scaling will be sharp at any density.
     Wrap in `Semantics(label: 'App icon', excludeSemantics: true)` so screen readers skip the
     decorative image.  Vertical spacing: `SizedBox(height: 16)` below the icon before the
     title.
   - **App name** ("Competition Manager Mobile") rendered in `headline-lg` (24 sp, bold).
   - **Short description** in `body-lg` (16 sp), centered. Suggested description, derived from
     the README:
     > "An Android app for glider pilots. Browse competitions, bookmark the ones you attend, and
     > download waypoint, airspace, and task files directly to XCSoar on your device."
   - **Version string** below the description in `body-sm` / `labelSmall` (subdued color).

   The entire identity block should have `EdgeInsets.symmetric(vertical: 24, horizontal: 16)`
   padding, consistent with the 16 dp horizontal grid defined in `docs/design/tokens.md`.
   All text in this block is center-aligned.

2. **Author row** — a `ListTile`-style row with a person icon and the text "Written by Andrey Lebedev".

3. **Source code / support row** — a tappable `ListTile` with a link icon (or `Icons.code`)
   and the label "Source & bug reports — github.com/kedder/compman-mobile". Tapping opens the
   URL in the device browser via `url_launcher`. The full URL is
   `https://github.com/kedder/compman-mobile`.

4. **"Data provided by" section** — a section header ("Data sources") followed by two
   `ListTile` rows, each tappable and opening the respective URL:
   - Competition data — soaringspot.com (`https://www.soaringspot.com/`)
   - XCSoar tasks — soarscore.com (`https://soarscore.com/`)

Visual rules from `docs/ui-guidelines.md` and the design tokens apply throughout:
- Colors from `Theme.of(context)` only; no hard-coded literals.
- No more than three type sizes on the screen.
- All tappable rows must meet the 48 dp minimum touch-target requirement.
- Tappable URL rows should use an `Icons.open_in_new` trailing icon to signal external
  navigation, consistent with standard Material conventions.

### App icon asset registration

The icon image lives at `assets/icon/app_icon.png` (1024×1024 px, RGBA PNG). The Flutter
`assets:` section of `pubspec.yaml` is currently commented out entirely, so the implementer
must uncomment/add the declaration before the image can be loaded at runtime:

```yaml
flutter:
  assets:
    - assets/icon/app_icon.png
```

Only `app_icon.png` needs to be declared; `app_icon_foreground.png` (the adaptive-icon
foreground layer) is consumed by the Android build system and does not belong in the Flutter
asset bundle.

### External URL opening

The app does not yet use `url_launcher`. This package must be added to `pubspec.yaml`.
It is a well-established Flutter plugin; adding it is low risk.

### No new navigation or state

This is a purely presentational screen. There is no async state beyond the existing
`packageInfoProvider`. No new Riverpod providers are needed.

per the documentation maintenance rule in `AGENTS.md`.
