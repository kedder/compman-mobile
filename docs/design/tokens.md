# Aviation Utility System — Design Tokens

## Color Palette
### Brand Colors
- **Primary (Sky Blue):** `#006591` — Used for primary actions and key brand elements.
- **Surface:** `#f9f9ff` — Main background color.
- **Surface Container:** `#f0f3ff` — Used for cards and secondary sections.

### Semantic Feedback
- **Success (Green):** `#059669` (Emerald 600) — Used for "Installed" states and positive confirmations.
- **Error (Red):** `#dc2626` (Red 600) — Used for error messages and failed operations.
- **Status - Live:** `#10b981` (Emerald 500)
- **Status - Upcoming:** `#006591` (Primary Blue)
- **Status - Past:** `#64748b` (Slate 500)

## Typography
- **Primary Font:** Inter
- **Headlines:** Semi-bold, tight tracking.
- **Body:** Regular, optimized for high readability on mobile devices.

## Layout & Spacing
- **Border Radius:** 4px (Utility/Technical feel)
- **Grid:** Standard mobile-first grid with consistent 16px padding.
- **Shadows:** Minimal to flat (utility-first aesthetic).
